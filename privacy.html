Privacy Policy — Homelab Backups

Last updated: October 12, 2026

Homelab Backups is a privately operated tool for backing up and restoring its operator’s personal homelab data. It is not offered to the public, and it does not collect data from public users through this website.

Google Drive access

The tool uses rclone with Google’s drive.file permission. That permission covers specific Drive files used with the app; it does not grant general access to every file in the account. The tool uses that access to store, read, and manage its backup repository for backup and recovery operations.

Backup contents and protection

The repository is designed to hold application backup data, not media libraries. Restic encrypts repository data before it is uploaded to Google Drive. Google Drive may still process file metadata needed to store and manage those files.

Credentials and storage

OAuth credentials and the Restic repository password are managed through a secrets manager and supplied to the private backup host, where runtime files are restricted to the host administrator. The repository does not document a fixed retention period; backups are retained or removed under the operator’s backup policy.

Sharing and service providers

Backup contents are not made public or shared with other users. Google provides the Drive storage. A secrets-management provider handles credentials, but does not receive the backup repository as part of the documented design. GitHub Pages hosts this public information site; Cloudflare provides DNS for its domain. Those services are not used to process backup contents.

Access revocation and questions

The operator can revoke the app’s Drive access through Google Account security settings. This tool has no public user accounts or public contact form.
